# Porting traps

Python behaviors that a literal translation gets silently wrong. Each trap names the Python source, the Rust hazard, and the countermeasure. Read the relevant rows before porting a module. Add new traps as you find them (with the commit that fixed them) and log AI misses in [AI_LEDGER.md](../AI_LEDGER.md).

| ID | Area | Python behavior | Rust hazard | Countermeasure |
| --- | --- | --- | --- | --- |
| T-1 | Templates (`naming.py`, `filename.py`) | `string.Formatter().parse` + `format(value, spec)`: `{{`/`}}` escapes, conversions (`!r`) rejected, specs limited to `0?[1-9]d?` (naming) or `[1-9]`/`0[1-9]` (filename) | No equivalent. `format!` is compile-time | Write a tiny hand parser (literal / `{name[:spec]}` / escapes). Property-test it against the Python parser output for generated templates in the differential job |
| T-2 | Sort order (`scanner.py`) | `sorted(Path)` orders by code point | Rust `String` order is UTF-8 byte order, which equals code point order. `OsString` on Windows is UTF-16 order, which differs for astral chars | Convert names to `String` first (ADR-0004), then sort. **Correction (SG-4):** on Windows `pathlib` sorts case-insensitively (lowercased parts); mirror that per platform. Test a non-BMP file name |
| T-3 | `path_key` (`safety.py`) | `NFC(abspath).casefold()` | No casefold or normalization in `std` | `unicode-normalization` (NFC) then `caseless::default_case_fold_str`. Conformance and property tests: `ß`/`SS`, `é` composed vs decomposed, Turkish `İ` |
| T-4 | `os.path.abspath` | Purely lexical: resolves `.` and `..` without touching the disk | `std::path::absolute` keeps `..` on Unix; `canonicalize` hits the disk and resolves symlinks | Write `lexical_absolute()` and test it. Never call `canonicalize` in key computation |
| T-5 | Publish/rename (`safety.py`, `filesystem.py`) | `os.rename` fails if the target exists on Windows; `os.replace` replaces. Exclusive publish on POSIX uses a hard link | `std::fs::rename` replaces an existing target on **all** platforms | Never use `fs::rename` for a no-overwrite publish. New destination: `fs::hard_link(staging, dest)` then remove staging. Replace: `fs::rename`. Test that a destination created after preflight survives ([ADR-0003](../adr/0003-no-unsafe-exclusive-publish.md)) |
| T-6 | Link detection (`is_link`) | `S_ISLNK` or Windows `FILE_ATTRIBUTE_REPARSE_POINT` | `symlink_metadata().is_symlink()` misses some Windows reparse points | On Windows also check `MetadataExt::file_attributes() & 0x400`. Test junctions and symlinks in the Windows CI job |
| T-7 | Whitespace (`naming._component`) | `re.sub(r"\s+", …)` with Unicode `str` patterns uses `str.isspace`, which includes `\x1c`–`\x1f` | `char::is_whitespace` (White_Space property) excludes them | Define `is_py_space(c)` explicitly; test all code points 0..=0x10FFFF against a table generated from Python |
| T-8 | Unicode categories | `unicodedata.category(ch) in {"Cc","Cf","Cs"}` | Rust `char` cannot be a surrogate; no category API in `std` | `unicode-general-category` for `Cc`/`Cf`; `Cs` is unreachable in `str`. Note Unicode version skew between Python 3.13 and the crate; pin and record |
| T-9 | Length limits | `len(s.encode("utf-16-le")) // 2 > 255` and UTF-8 byte length | `s.len()` is UTF-8 only | `s.encode_utf16().count()` and `s.len()`; test with emoji at the boundary |
| T-10 | Rounding (`effect_chain.py`) | `round()` is banker's rounding (ties to even) | `f64::round` rounds ties away from zero | `f64::round_ties_even`. Test `0.5`, `1.5`, `2.5` samples |
| T-11 | Float text in filters | `f"{x:.17g}"` | Rust `{}` prints the shortest round-trip form, never an exponent; `{:e}` differs | Rust's shortest round-trip is numerically identical, so FFmpeg sees the same value. Check whether filter strings reach any contract output; if they do, implement `%.17g` exactly, otherwise use `{}` and record the decision |
| T-12 | Type checks | `isinstance(v, bool)` guards because `bool` is an `int` | JSON `true` and `1` are distinct `serde_json::Value` variants | Parse config into typed structs with `deny_unknown_fields`; reject floats where ints are required (`1.0` is not `1`) and vice versa as Python does. Cover with config tests ported from `test_cli.py` |
| T-13 | Process spawning (`ffmpeg.py`) | Env allowlist (`SystemRoot`, `WINDIR`, `TEMP`, `TMP`, `LANG=C.UTF-8`); new process group; kills the whole group on POSIX; stdin = null; stdout/stderr to temp files, polled | `Command` inherits the env by default; group kill needs `unsafe` or a crate | `env_clear()` then the allowlist; `CommandExt::process_group(0)` (unix) / `creation_flags(CREATE_NEW_PROCESS_GROUP)` (windows); `nix::sys::signal::killpg` for group kill; always `wait()` to reap. Bound captured output while reading, not after |
| T-14 | Config JSON (`cli._load`) | Rejects duplicate keys, non-finite constants (`NaN`, `Infinity`), exponent overflow (`1e999`), accepts a UTF-8 BOM, 1 MiB cap, regular file only | `serde_json` accepts duplicate keys silently, rejects BOM | Read bytes with a size cap, strip the BOM, then parse with a visitor that errors on repeated keys. Test `1e999`, `NaN`, `-Infinity`, duplicate keys at every nesting level |
| T-15 | String predicates | `str.isdigit`, `isalnum`, `isascii` | `char::is_numeric` accepts non-ASCII digits | Use `is_ascii_digit` etc. where Python guards with `isascii()` first; replicate exactly where it does not (`captured.isdigit()` after `isascii()` ⇒ ASCII digits only) |
| T-16 | Globs (`--pattern`) | `fnmatch.fnmatch` applies `os.path.normcase`: case-insensitive on Windows only. Supports `*`, `?`, `[seq]`, `[!seq]` | `glob`/`globset` have different bracket and separator rules | Write the matcher in ~60 lines. **Correction (SG-5):** `Dir` calls `fnmatchcase`, so matching is case-sensitive on every OS |
| T-17 | Allow/deny regex (`listing.py`) | `re.match` = anchored at the start only; Python `re` syntax | The `regex` crate lacks backreferences and lookaround | Use `regex` with a leading `\A(?:…)`; document the syntax difference as a spec gap. The CLI exposes only globs, so this is library-only |
| T-18 | Windows names (`naming.py`) | Device names `con prn aux nul conin$ conout$ com1-9 lpt1-9` plus superscripts `¹²³`; check on the stem before the first `.` | Easy to test only ASCII | Port the set verbatim; test `COM¹`, `nul.txt`, `Con.` |
| T-19 | Same-file detection (`safety.destinations`) | `os.path.samefile` | `std` lacks it | `same-file` crate (safe wrapper). Needed for case/Unicode alias rejection on case-insensitive filesystems |
| T-20 | Cleanup on failure | `try/finally` removes staging | `?` early returns skip cleanup | Use an RAII guard (`StagedFile` with `Drop`) so every path, including panics, removes owned staging files. Failure-injection tests assert no leftovers |
| T-21 | Cancellation | `OperationCancelled` is an `InterruptedError` subclass, kept distinct from EINTR | Using `io::ErrorKind::Interrupted` conflates them | Dedicated `AudError::Cancelled`; never map from `io::Error` |
| T-22 | Path text in JSON | Paths serialize as `str(Path)`; conformance compares with `/` separators after `$ROOT` replacement | `Path::display()` yields `\` on Windows | One helper `portable(path) -> String` for contract output. Follow the corpus README for which fields are paths |
| T-23 | Archive determinism (`packaging.py`) | Manifest and checksum content; ZIP member order; timestamps | `zip` crate defaults differ | Read `packaging.py` and `spec/ALBUM_PACKAGING.md` fully at M6; compare member lists and manifest JSON, not ZIP bytes |
| T-24 | Mutation in resolve | Python mutates dataclasses in `resolve`; plan snapshots | Borrow checker will push you toward cloning | Make plan types immutable and `Clone`; resolve into a new `Vec<Step>` |
| T-25 | Panics in library code | Exceptions are the only failure channel | `unwrap`, slicing, and integer overflow can panic | Return `Result`; `checked_*` arithmetic on sizes and counters; fuzz parsers (M8) |
